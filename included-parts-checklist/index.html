Included Parts Checklist

Check the text and image boundary for single items, sets, accessories, packaging, and add-ons.

What is included is part of the option

The same item name can mean very different things once you read what actually comes with it. Go through the checklist below so a set is not mistaken for a single item, and a shown accessory is not mistaken for an included one.

Single item versus set

Confirm whether the option is one piece or a set, and note the number of pieces in the set. A set with different contents is a different option.

Explicitly included parts

Only parts stated in the text as included should be treated as included. A strap, lid, or insert named in the description is a declared part.

Image-displayed parts

Parts that appear only in a photo are shown, not necessarily included. The image shows what the item looks like; it does not confirm what is in the box.

Packaging display

Boxes, dust bags, and other packaging shown in images are display items. Confirm in the text whether they are actually included before counting them.

Optional add-ons

Parts offered as an optional add-on are separate from the base option. Record them as add-ons, not as included parts.

Manifest ruleRead the text for what is declared, read the images for what is shown, and keep the two separate. Only the declared parts are included.
!Open item: is a shown accessory treated as included, or left open until the text confirms it?

A worked checklist

  1. Single or set: the title says set — noted as a set.
  2. Included: the description names the strap and the cover.
  3. Shown only: the photo shows a box — left open until confirmed.
  4. Add-on: an extra insert is offered separately — recorded as an add-on.
  5. Result: the declared parts are separated from the shown parts.
